Ce face

Codex Judge evalueaza local solutii scrise in C++17 si Python 3. Alegi o problema, trimiti codul si primesti un verdict pentru fiecare exemplu public si test privat. La un exemplu public gresit, raportul poate indica prima valoare diferita sau un numar incorect de valori, ca sa stii unde sa incepi depanarea.

Cum ruleaza evaluarile

Interfata trimite codul catre un API Python, care pune trimiterea intr-o coada SQLite. Un proces de fundal preia trimiterea, compileaza codul C++ sau verifica sintaxa Python, apoi ruleaza fiecare test intr-un container Docker separat. Limitele de timp si memorie fac posibila diferentierea intre un raspuns gresit si o solutie care depaseste resursele alocate.

Punctaj partial

Scorul din 100 este media punctajelor obtinute pe teste. Un test corect primeste punctaj integral. Daca iesirea are lungimea asteptata, dar numai 4 din 5 valori sunt corecte la pozitiile lor, testul primeste 40% din punctajul sau si pastreaza verdictul „Raspuns gresit”. O eroare la rulare sau un numar gresit de valori aduce zero pentru acel test.

Probleme proprii si cataloage

Poti importa titlul si exemplele publice disponibile din PbInfo, CSES si AtCoder sau poti crea propria problema. Poti genera iesiri folosind o solutie de referinta si adauga un verificator personalizat. De exemplu, la o problema de drum minim, verificatorul poate accepta doua trasee diferite daca ambele sunt valide si au costul minim.
