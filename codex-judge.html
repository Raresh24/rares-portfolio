Ce face

Utilizatorul alege o problema, trimite o solutie si vede verdictul pentru fiecare test. Pentru exemplele publice care esueaza, raportul arata prima diferenta din iesire sau diferenta de lungime.

Cum ruleaza evaluarile

Browserul trimite solutia catre un API Python. Trimiterile intra intr-o coada SQLite, iar un worker compileaza codul C++ sau verifica sintaxa Python si ruleaza fiecare test intr-un container Docker separat. Istoricul si problemele proprii sunt pastrate in SQLite.

Punctaj partial

Scorul din 100 este media scorurilor pe teste. Un test acceptat primeste punctaj integral. Pentru iesiri de lungime corecta, dar cu valori gresite, compararea standard acorda jumatate din proportia valorilor corecte pe pozitiile lor. De exemplu, patru valori corecte din cinci aduc 40% din punctajul acelui test.

Probleme proprii si cataloage

Aplicatia importa titlul si exemplele publice disponibile din PbInfo, CSES si AtCoder. Pentru probleme proprii poti adauga teste private, seta limite de timp si memorie, folosi o solutie de referinta pentru a completa iesirile si defini un verificator pentru probleme cu mai multe raspunsuri valide.

Disponibilitate

Proiectul ruleaza local cu Python si Docker.
